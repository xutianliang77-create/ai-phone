# 结束回执丢失的恢复边界（第84批验收）

复用原公有结束、server-observed停止水位、原唯一结算及手机检查点，没有新增生产接口或自动重连机制。

- **服务端已结束，回执丢失**：保留手机待结束记录；用户在原页面明确确认后，按同账号/部署/session查询并接受绑定的原回执，不创建替代收费会话，不重放音频。服务端同键重复finalize返回原回执，不再结算。
- **停止证据已落盘，结算暂时失败**：保留预占和待确认状态，不显示已结算。客户端恢复窗到期后仍不能越权finalize；原服务端过期恢复可在可信停止证据完整时补做唯一结算，随后手机再确认。
- **没有可信停止证据或计量不确定**：保持未决，不能推断零费用或直接释放。供应商预算/费用对账不由手机重试或用户预占状态代替。
- **账号切换**：新账号不读取或发送旧账号待办；切回原账号后按原键继续。停止/确认都不意味着跨账号迁移。

本机loopback＋合成模型覆盖三次stopped回执丢失、唯一结算和原译文保留；API应用重建/序列化重载后仍返回原回执。手机使用真实临时文件重建API/Repository/Store，验证尾句、业务类型与待办恢复，且不新增Gateway连接、模型创建或finalize POST。

测试时间推进是模拟时钟，不是15分钟实测；应用对象重建不是操作系统进程重启、数据库主从切换或整机恢复。本批未进行真机/真实供应商或多实例验收，也未部署。

原计划中的运行中公有无损断线续接仍未实现。这里的“恢复”仅指已停止会话的回执和最终状态确认，不代表恢复采音/翻译连接。原1.0冻结和公有生产准入门禁不变。
