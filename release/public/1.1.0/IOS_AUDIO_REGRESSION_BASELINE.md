# iOS 在线音频专项基线与防回归规则

## 冻结什么，不冻结什么

本次专项基线是源提交 `25f3eb315461b8aaa6d6af22e96fc95020ce10c9`、公有 App `1.1.0 / 2026093008` 和对应隔离服务端。精确源码树、App/manifest/image/配置指纹及验收回执摘要见 [ios-audio-acceptance-baseline.json](ios-audio-acceptance-baseline.json)。当前已安装包保持原样；新增测试/CI/构建保护不表示重新构建、安装或部署过新运行时。

这不是整个1.1正式发布冻结，也不修改冻结1.0。不锁死供应商、语种或音色：ASR/MT/TTS仍按原配置页选择；更换影响链路的配置后，按原方案补相应资格和设备证据，不冒用本基线。

## 已验收范围

- 同一iPhone内置麦克风/扬声器；初始音频配置变化后真实首帧与持续采音正常。
- 安静时6个TTS块完整播放，19个朗读/尾期分析窗参考完整，无误取消；本条实际安静尾段13.511秒，未充当完整20秒或长测。
- 真正插话时，本地speechStarted为8667ms，旧播放8669ms取消；这是检测事件到取消的2ms日志间隔，不是开口延迟或性能SLA。
- 新句得到原译文并重新朗读；手机/服务器历史一致、pending0、正常结束、单会话唯一结算。
- 用户确认无问题并另做补充测试；非固定补充内容不误判成幻听，也不计入固定质量评分。

蓝牙/其他路由、后台/来电、长测和原质量盲评仍按各自原任务和证据收口。此文不将这些范围整体标为通过。

## 必须保留的实现约束

1. **图就绪不等于首帧就绪。** 配置恢复检查引用/AEC图，不在首帧前要求输入时钟；对App宣布开始成功仍必须有真实首PCM和有效时钟。
2. **真实render，不是排程时刻。** 公有播放与麦克风使用同一voice-processing图；回声参考来自mixer实际输出。
3. **连续PCM按设备sampleTime拼接。** hostTime作为锚点；真实样本缺口、时钟重启、速率变化和旧代际不能被补零、重放或拼成连续音频。
4. **正常分片完成不能stop。** 只有真实取消、替换或结束才能清播放；旧回调不能结束新一代播放。
5. **有人声不等于用户插话。** 回声/未知参考保护与独立近端语音要同时验证；不得通过全程禁麦或单纯放宽阈值取得表面通过。
6. **原生→Dart停止链保留。** 确认的speechStarted进入startsSegment，在已有公有播放上触发_stopSpeaking；新话轮仍能翻译、播放和保存。

## 每次怎么检查

在macOS/Xcode上执行，无须手机、模型、凭据或网络：

```sh
npm run check:ios-native-audio -- --output /absolute/new-path/native-audio-regression.json
```

6组原生用例复用实际实现，覆盖采音恢复、采样时钟、播放生命周期、引擎所有权、VAD起点以及脱敏标量驱动的打断/恢复。测试使用合成PCM和脱敏数值，不保存或提交用户录音。非macOS、工具缺失、任一编译/用例失败、执行中源码变化必须非零退出，不写成跳过即通过。

`scripts/build_traceable_ios_candidate.sh` 在构建前强制执行该入口；新候选manifest必须包含同一干净commit/tree/输入哈希的完整成功回执摘要。缺失、脏工作树、旧源码、缺用例或非零结果均拒绝生成成功manifest。没有跳过开关。

`.github/workflows/ios-native-audio.yml` 增加独立macOS CI检查，保持只读权限、固定Action SHA及不持久化checkout凭据。现有Node/Flutter和冻结1.0双版本检查不变。新增CI配置未推送前不代表远端CI已运行；是否将检查设为GitHub分支必需项属于单独的远端管理操作。

## 后续真机验收与回滚

- 改动上述链路、平台音频SDK、相关播放/VAD设置或供应商音频协议时，在对应同源候选上做“安静完整朗读”和“真正重叠插话”两条原验收，核原生时间线、结束回执、手机历史和唯一结算。
- 插话应在听到**任意首词**时开口，不依赖某供应商固定译文或特定单词；朗读结束后才说话不算插话测试。用户补充的句子单独标注。
- HOST_PASS、目标构建、部署、DEVICE专项通过与正式发布分开记录。不得用一次静听通过替代插话，也不能把结束时的cancelled当作插话成功。
- 回退保留3008签名包、符号、源归档和匹配服务端/配置。不得清沙箱、覆盖私有1.0或只换一端而冒称同源；回滚仍按既有授权、空闲和数据保护规则执行。

原始真机回执保留在工作区证据目录，仅提交摘要、哈希和脱敏标量。已授权的临时诊断录音在分析/受影响复验完成后按清单清理，产品历史不删。
