## 请求流程

原账号/部署校验 → GET /realtime/sessions/configuration?voiceOutput=true或false → 先原子保存无密钥请求身份 → 原POST /realtime/sessions携带Idempotency-Key → 校验响应 → 原Gateway连接并等待匹配session.started → 标记该请求已连接 → 原采集/显示/播放流程。

GET响应是配置说明，不是模型资格或授权。它包含当前owner/部署、revision、执行计划、采样率、WSS端点和可选配置声音，不返回模型密钥。只有原服务端可信协调来源接入时才可用；不能靠手机body或配置页开启生产。

手机要求HTTPS且禁止重定向，沿原账号核验，操作中账号/代际变化或停止会拒收迟到结果。Token载荷仅用来校验响应一致性；手机不验证服务器HMAC，实际验签/当前授权仍由Gateway负责。

## 请求键和停止

应用支持目录的public_creation_v1作用域文件使用原子写入，保存账号/部署/API作用域hash、settings摘要、随机键、无密钥body、endpoint及状态。它不保存登录Token、会话Token、供应商密钥或录音/原译文。

未知结果必须保留同键/同body；并发开始或客户端重建重试不会自动新建收费会话。收到session.started且账号/操作未变才消费该键；之后新的明确开始可生成下一键。文件损坏拒绝，不清空重建。

停止先取消HTTP/待确认连接，迟到响应不能打开新Gateway。公共音频在匹配started前禁发；错误会话事件忽略，启动错误/关闭/超时拒绝。公有断线不自动重连、不重放未知音频；私有路径不受此公共限制改写。

## 未决创建操作（第83批）

会话停止后，在原同传页点“查看未决创建”。这只查询当前账号/部署/API作用域内已保存的原请求，不新建会话。not_found不证明请求不会迟到，expired_pending也不是已经处置完毕；原键仍保留。

若返回可处置状态，可明确点“撤销未开始请求”；已过期还可点“确认过期处置”。二次确认只针对刚查询的请求，不删除历史、不处理已有运行/输出/计费证据的会话，不自动创建下一会话。身份、部署、原键/正文hash、随机nonce和状态必须匹配，cancelled/expired回执保存成功后，界面才提示可修改设置并手动开始。

处置期间开始受互斥保护，可“停止等待”。账号切换、网络失败、错误回执、写盘失败会保留未决状态；服务端可能已完成操作时，重新查询原键补取回执，不换键猜测。reconciliation_required明确转原结束确认/对账，不能按“未使用”释放。供应商费用不因此视为零。
