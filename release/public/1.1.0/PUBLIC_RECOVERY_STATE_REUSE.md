# 原Gateway恢复状态复用边界（第88批）

第88批在原session map中增加一份**仅内存、仅同进程**的恢复对象。它只保存已经建立的Provider、公共确认sink和已暂停的TTS队列；不包含Token、凭据、音频、原译文、账本或用户数据。

## 何时可以暂存

必须同时满足：原Gateway先排空已接收内容；原公共sink已经写入并确认`disconnected`水位；原session仍是同一连接代际的connecting状态；并且启动时显式传入测试装配开关`recoverySocketAssembly=true`。默认值为关闭，因此普通公共断开仍沿原立即结束和唯一结算流程。

暂存不刷新原恢复窗口。到达原截止时，已有finalizer仍结束Provider、释放TTS队列并删除会话；显式删除同样释放一次。没有后台永久连接或无限缓存。

## 不能据此推断的事情

- 暂存对象不是新的WebSocket入口、不是API/数据库的所有权锁，也不是跨Gateway/进程恢复机制。
- 它不准许读取凭据、续签Token、重放已接收音频或创建替代会话。
- 新Socket尚未接入这份对象；Provider重新绑定、确认sink重新绑定、TTS恢复、音频序号与当前API授权校验仍是后续工作。
- 只有在后续每一环均成功并通过同会话/水位/停止/唯一结算验证时，才可评估端到端续接。当前仍不能将真实断网恢复签收为通过。

此批为原V11-08/26的安全前置。它不改变本地/在线模型分工，不部署或调用真实供应商。

第89批已在显式测试开关下将这份对象接入[受限恢复Socket装配](PUBLIC_RECOVERY_SOCKET_ASSEMBLY.md)。新Socket仍拒绝音频，默认生产开关仍关闭；状态复用不能单独构成用户可用续接。
