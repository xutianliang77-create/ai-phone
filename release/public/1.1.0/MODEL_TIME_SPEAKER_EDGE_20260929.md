# CO11-06：真实130ms模型时间边缘关联缺陷

基线：0118b8f / iOS 2026092901。同一轮手机日志、Gateway日志、数据库与手机历史均保留在外层 `artifacts/closeout-regression/20260929-evidence-closure/`。这份修复不改VAD、Sortformer权重、cache31、活动阈值、ASR/MT/TTS配置或价格。

## 根因证据

- 首轮70秒固定音完整播放。正常结束、唯一76秒，12条原译文；手机与服务器正文、语言、revision、说话人、数值时间相同，pending0。原始JSON的12处差异仅是已定义的 `overlap:false` / `activeSpeakerIds:[]` 序列化省略，规范化后0差异；原始比对不覆盖或删除。
- VAD、手机说话人和Gateway各743批输入，样本范围完全相同。手机两个消费者的743份摘要一致；741份Gateway摘要可逐字比对，另外2份被原日志手机号脱敏规则截断，只标为不可完整比较，不当作PCM损坏或完整通过。
- 928帧原始模型概率经相同ActivityDecoder重放，与手机输出spans完全相同；155个手机证据包与Gateway逐包一致，额外第156包为原规则的不足80ms空尾部水位。没有重做ASR或模型推理。
- 术语句时间为47390–54185ms，79个手机span全部属于匿名说话人1；单独运行原 `deviceSpeakerAlignment` 得到说话人1。已确认换人边界在47520ms，即距句首130ms。原 `attributeDeviceSpeakerBoundary` 的边缘修复只允许 `source=estimated`，所以实际 `source=model` 被无条件留为unknown。该路径在完整后到证据抵达后仍未修正。
- 会议长句另有手机原始slot2/slot0变化，不能用这个修复强行合并；是否是真实声源变化或模型误分，仍需受控声学复核。首轮尾句标点本次正确，不把未复现当成已修复。未播放固定音的另一条104秒会话无字幕/MT，也不是完整验收。

## 最小修复

复用原单说话人覆盖率/置信度规则，仅为模型时间增加受限边缘入口：

1. 证据来自原手机验证路径，sequence从1连续，完整水位已覆盖整条ASR时间窗；缺包不能当作无声。
2. 时间窗尚在原120秒保留范围内；容量淘汰过的前缀不能声称完整。
3. 仅一个已知边界，位于句首/尾小于原160ms阈值范围；内部/多个边界仍保守。
4. 全段没有任何竞争说话人span，即便只有1ms也不忽略；重叠、显式不同speaker、低置信度或覆盖不足均不修复。
5. 不改正文、word timings、source/target或音频；源组句路径可使用已有确认turn引用，纯metadata更新仍不移动已存turn，避免晚到MT回滚归属。

不同ASR供应商只要提供有效 `source=model` 时间且手机证据完整，均走同一规则；没有硬编码Qwen型号。私有默认归属及旧estimated路径保持。

另外，诊断额外记录32个数值摘要字节。原hex摘要仍接受原脱敏器处理，真实手机号/token仍脱敏，不增加隐私白名单。新候选首批音频也记录实际输入/输出port类型、音频模式和硬件采样率，便于排除路由问题；不记录设备名、UID或录音。

新增真实采样fixture只含该技术句、时间与匿名spans，无账号、token或原始音频。覆盖真实130ms正例、句尾、精确词时间不变、缺包/未完成水位、过期/容量淘汰、1–159ms竞争voice、重叠、多边界、低置信/覆盖、客户端时钟、已有不同标签、原私有行为。
