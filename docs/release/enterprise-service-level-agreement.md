# 无界AI企业版服务等级说明

状态：未批准，不承诺具体 SLA、RPO 或 RTO

## 1. 适用范围

正式 SLA 按已签署的企业订单、服务区域、能力包和例外条款生效。试用、演示、第三方
Provider 故障、客户网络/设备、客户错误配置和法律要求导致的暂停必须在正式条款中明确。

## 2. 内部 SLI

候选发布至少采集控制面路由和开通、API 成功率和延迟、RTC 入会/重连/丢帧、首段字幕、
最终字幕、翻译、首音频、PSTN claim/webhook、客服接管、共享首帧、数据库锁等待、
Outbox age、备份归档和恢复校验。内部 SLI 不自动等于客户 SLA。
订阅链路还需采集签名拒绝率、event-to-decision延迟、command backlog/重领、欠费阻断延迟、恢复新权益延迟和账期
对账差异；未完成真实支付与财务验收时这些指标不构成客户承诺。

## 3. 事件等级和支持

- P0：多租户安全边界、不可恢复数据风险或核心服务大面积不可用。
- P1：单区域/Cell 或关键能力严重降级，存在明确业务影响。
- P2：有替代路径的局部能力故障。
- P3：一般缺陷、咨询或文档问题。

正式材料必须填写支持时段、首次响应目标、状态更新频率、升级路径和客户通知渠道；这些
值需由运营、法务和客户合同共同批准，不能在代码模板中预设。

## 4. 灾备目标

RPO/RTO 只有在 H3 使用至少两个数据库故障域、第三备份故障域、旧主 fencing、加密
WAL、不可变保留和隔离 PITR 实测后才能批准。manifest 的 H3 evidence 必须绑定同一
candidate commit/image、数据库 manifest、演练拓扑、实测值和独立 reviewer。

## 5. 排除虚假就绪

单机双库、人工 promote、只确认备份文件存在、mock Provider、健康检查或历史其他分支
证据都不能作为 SLA 达成证明。没有批准证据时控制台和发布材料只显示 `not_ready`。
