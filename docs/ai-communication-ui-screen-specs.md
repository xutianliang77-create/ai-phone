# AI 通讯翻译页面规格补充

版本：v0.2  
日期：2026-07-03  
关联文档：`docs/ai-communication-ui-design.md`  
用途：补充 Call Link、通话房间、AI Agent、扫描、记录、我的等页面细节。

## 1. Call Link 创建页

布局：

```text
发起翻译通话

我说：[中文 v]
对方说：[英文 v]

通话类型
( ) 语音  ( ) 视频

对方加入方式
[生成链接]

链接说明
对方点击链接后即可在浏览器加入翻译通话。
```

生成后：

```text
翻译通话链接已创建
[复制链接] [分享到微信] [分享到 WhatsApp] [短信]

等待对方加入...
```

校验：

- 必须选择语言。
- 免费用户点击生成链接时进入付费/credits 提示。
- 链接过期后显示重新生成。

## 2. 通话房间页

布局：

```text
正在通话  08:42                  [静音] [键入] [结束]

我说中文 -> 对方听英文
对方说英文 -> 我听中文

我：我想预约明天下午三点。
I would like to make an appointment for 3 PM tomorrow.

对方：Can you spell your name?
对方：你能拼一下你的名字吗？

[输入并朗读] [标记重点] [切换语音]
```

字幕规则：

- 我方原文左对齐。
- 对方原文左侧显示“对方”标签。
- 译文使用次级颜色。
- Type-to-Speak 内容显示键盘图标。
- 自动重点显示细描边标签。

## 3. 拨打手机号页

布局：

```text
拨打手机号

对方号码
[+1 415 555 0198]

对方语言
[英文 v]

我的语言
[中文 v]

通话说明
对方会接到普通电话。接通后系统会播放翻译语音。

费用预估
约 2-5 credits / 分钟

[确认拨打]
```

确认弹窗：

```text
确认发起翻译电话？
系统会通过电话服务商拨打对方号码，并生成转写和摘要。
[取消] [拨打]
```

状态页：

```text
正在拨号...
等待对方接听

[取消拨号]
```

校验：

- 号码必须符合目标国家格式。
- 必须有剩余 credits。
- 必须显示费用预估。
- 必须展示录音、转写和 AI 翻译提示。
- 接通后进入通话房间页。

## 4. AI Calling Agent 任务页

布局：

```text
AI 帮我打电话

我要做什么？
[预约] [查询] [取消/改期] [联系客服] [自定义]

对方电话
[输入号码]

任务说明
[我想预约明天下午三点洗牙，如果没有三点，下午四点也可以。]

我的信息
[姓名] [电话] [地址] [备注]

[生成话术草稿]

状态：待确认 / 已授权 / 排队中 / 通话中 / 已完成 / 失败 / 需要接管 / 已取消
话术预览
Call ID / 结果摘要 / 失败原因 / 下一步
[确认授权] [开始执行] [刷新状态] [人工接管] [取消任务]
```

预览页内容：

- AI 将如何开场。
- 可接受的时间、价格、条件。
- 必须转人工的情况。
- 用户确认前可取消，取消后不进入拨号队列。
- 用户确认、开始执行和刷新状态按钮。
- 国内版当前必须先保存草稿和授权记录；执行服务未配置时显示错误，不自动外呼。
- 真实 Worker 回写后展示 call id、执行状态、结果摘要、失败原因和下一步。

通话监控页内容：

- 实时转写。
- AI 当前意图。
- 对方回答。
- 接管按钮。
- 结束按钮。

## 5. 扫描翻译页

布局：

```text
扫描                         [相册] [历史]

[相机取景框]

[拍照] [相册] [截图]

识别结果
[原文] [译文] [对照]
```

结果页操作：

- 复制原文。
- 复制译文。
- 重新识别。
- 保存记录。
- 分享。

状态：

- 相机未授权。
- 正在识别。
- 识别失败。
- 翻译失败。
- 已保存。

## 6. 记录列表

布局：

```text
记录                         [搜索] [筛选]

全部 | 同传 | 通话 | 扫描 | AI Agent

医生预约通话
12 分钟 · 中英 · 已总结 · 3 个重点

课堂听讲
48 分钟 · 英中 · 待总结
```

筛选：

- 类型。
- 日期。
- 是否有摘要。
- 是否有重点。
- 是否已导出。

空状态：

```text
暂无记录
完成一次同传或通话后，会在这里看到双语转写和摘要。
```

## 7. 记录详情扩展

重点 Tab：

- 自动重点。
- 用户手动重点。
- 按时间、地点、金额、待办分类。

术语 Tab：

- 本次识别错误。
- 建议加入术语库的词。
- 用户确认后写入术语库。

导出弹窗：

```text
导出记录
[Markdown] [PDF] [纯文本]
[包含摘要] [包含重点] [包含全文]
```

## 8. 我的页

分组：

- 语言：默认中英、自动识别、目标语言。
- 语音：中文声音、英文声音、语速、自动播放。
- 术语库：新增、导入、启用；同传设置已支持单选通用、商业、科技、医疗、旅游、餐饮、娱乐行业包，修改在下一次 session 生效。
- 隐私：端侧优先、不保存音频、删除记录。
- 用量：本月同传分钟、通话 credits、AI 总结次数。
- 订阅：Free、Pro、Plus、Credits。

隐私页必须显示：

- 端侧 ASR 状态。
- 是否上传音频。
- 是否保存原始音频。
- 历史删除入口。

## 9. 订阅和 Credits 页

套餐展示：

- Free：免费分钟、历史限制、基础扫描。
- Pro：同传、导出、AI 摘要、基础术语库。
- Plus：通话房间、AI Agent、高质量云模型。
- Credits：电话、视频、AI Agent、云端 TTS 按量扣费。

购买前说明：

- 自动续订规则。
- credits 用途。
- 隐私处理方式。
- 取消订阅入口说明。

## 10. 语音设置页

设置项：

- 中文声音。
- 英文声音。
- 语速。
- 自动播放译文。
- 耳机优先播放。
- 使用我的授权语音。

自定义语音提示：

- 仅可录制自己的声音。
- 可随时删除。
- 删除后不能继续用于新通话。
