# AI 通讯翻译界面设计文档

版本：v0.2  
日期：2026-07-02  
关联文档：`docs/ai-communication-feature-design.md`、`docs/ai-communication-ui-screen-specs.md`  
设计目标：界面中文优先，移动端 iOS/Android 共用 Flutter 实现，强调低学习成本、实时状态清晰、通话中可单手操作。

## 1. 设计原则

- 首页不是宣传页，打开就是可用的同传工作台。
- 中文界面优先，英文作为设置里的可选语言。
- 通话中按钮数量要少，核心操作固定底部。
- 字幕区域最大化，避免卡片堆叠。
- 重要状态必须可见：收音中、翻译中、播放中、已暂停、网络差、余额不足。
- 电话和 AI Agent 涉及风险操作时必须二次确认。

## 2. 全局导航

底部 Tab：

```text
同传 | 通话 | 扫描 | 记录 | 我的
```

顶部通用按钮：

- 语言：打开语言和自动识别设置。
- 隐私：显示端侧/云端处理状态。
- 历史：跳转最近记录。

全局状态条：

```text
端侧 ASR 已就绪 | 云端翻译可用 | 剩余 268 分钟
```

## 3. 视觉风格

建议方向：

- 工作型、清晰、低干扰。
- 背景浅色，字幕区域留白充足。
- 主色使用沉稳绿色或蓝绿色，避免大面积渐变。
- 按钮圆角适中，图标按钮配 tooltip 或可访问标签。
- 通话中危险操作使用红色文字或描边。

字号建议：

| 元素 | 字号 |
| --- | --- |
| 页面标题 | 28-32 |
| 字幕原文 | 24-30 |
| 字幕译文 | 18-22 |
| 记录列表标题 | 16-18 |
| 状态和辅助信息 | 13-15 |

## 4. 同传首页

用途：面对面、听讲、键入朗读的统一入口。

布局：

```text
同传                         [语言] [隐私] [记录]
中英 AI 实时同传

[面对面] [听讲] [键入朗读]

自动识别中英文
状态：未开始

字幕时间线
...

[开始] [暂停] [结束]
```

组件：

- 分段控制：面对面、听讲、键入朗读。
- 状态文案：未开始、启动中、同传中、暂停、正在重启端侧 ASR。
- 字幕时间线：原文大字，译文灰色小字。
- 底部控制：开始、暂停、结束。

空状态：

```text
点击开始后，说中文会显示英文，说英文会显示中文。
```

## 5. 面对面同传页

字幕项样式：

```text
你叫什么名字？
What is your name?

This is a test.
这是一个测试。
```

交互：

- 长按字幕：复制、重新翻译、标记重点、纠正术语、播放译文。
- 点击译文：播放 TTS。
- 上滑查看旧字幕，停止自动滚动。
- 回到底部按钮：用户手动看旧内容后出现。

异常提示：

- 麦克风未授权：显示授权按钮。
- 无翻译结果：显示“正在补齐最后一句翻译”。
- ASR 重启：显示“正在重启端侧 ASR”。

## 6. Listening Mode 页

用途：课堂、会议、演讲，只听不播报。

布局：

```text
听讲                         [场景] [隐私]
状态：记录中  12:08

今天我们讨论产品计划...
Today we are discussing the product plan...

[标记重点] [暂停] [结束并总结]
```

差异：

- 默认关闭译文朗读。
- 字幕字号比面对面模式更大。
- 底部主按钮是“标记重点”。
- 结束按钮文案为“结束并总结”。

## 7. Type-to-Speak 弹窗

入口：同传页或通话页底部按钮。

布局：

```text
输入并朗读

原文
[王天亮，预约号 A1279]

目标语言
[英文 v]

[翻译] [播放给对方] [复制]
```

状态：

- 未翻译。
- 翻译中。
- 可播放。
- 播放中。
- 已插入记录。

快捷短语：

- 我的名字是...
- 我的地址是...
- 请稍等，我需要确认一下。
- 能否重复一遍？

## 8. 通话首页

用途：进入翻译通话、AI Agent、加入链接。

布局：

```text
通话                         [余额] [设置]

[发起翻译通话]
[拨打手机号]
[AI 帮我打电话]
[加入通话链接]

最近通话
医生预约通话      12 分钟    已总结
客户报价确认      18 分钟    3 个重点
```

卡片内容：

- 通话对象。
- 时长。
- 语言方向。
- 是否已总结。
- credits 消耗。

## 9. 通话中通用控件

通话顶部栏：

- 通话对象或房间名。
- 已通话时间。
- 当前网络状态。
- credits 消耗提示。

通话底部栏：

```text
[静音] [输入并朗读] [标记重点] [结束]
```

通话状态：

- 等待加入。
- 连接中。
- 通话中。
- 网络较差。
- 正在翻译。
- 正在播放给对方。
- 已结束。

结束确认：

```text
结束通话？
结束后将生成转写和摘要。
[取消] [结束并总结]
```

## 10. 拨打手机号页

用途：通过 PSTN 服务商拨打真实手机号，对方接普通电话。

布局：

```text
拨打手机号

对方号码
[+1 415 555 0198]

对方语言
[英文 v]

我的语言
[中文 v]

费用预估
约 2-5 credits / 分钟

[确认拨打]
```

拨号状态：

- 正在拨号。
- 等待接听。
- 已接通，准备翻译。
- 未接听。
- 忙线。
- 余额不足。
- 号码不可拨打。

## 11. 记录详情结构

顶部：

```text
医生预约通话
2026-07-02  12 分钟  中英
[导出] [分享] [删除]
```

Tab：

```text
摘要 | 重点 | 全文 | 术语
```

摘要 Tab：

- 一句话结论。
- 待办。
- 时间、地点、金额。
- 风险提示。

全文 Tab：

- 按时间线显示双语内容。
- 支持复制、播放、重新翻译。
