# 无界 AI 1.0：纯端侧拍照、自动双向、多语言与音色恢复方案

版本：2026-10-30，供审阅。**本文件是方案与测试计划，不是开发、安装、开窗或发布回执。** 以 iPhone 14 Pro、iOS 26 及以上为首版基线；设备上的 2908 与未安装的 3001 分开记录。原数据、冻结 1.0、1.1 未提交改动和既有备份均保留。

## 1. 目标与当前事实

1. 照片、语音、识别文字、译文和朗读内容均在手机处理；Vision OCR、Apple SpeechTranscriber、系统 Translation 和系统 TTS 优先复用，不调用线上或自有模型服务器，不将业务内容送到 Cloudflare。账号、订阅、设备认证与短许可仍由现有控制服务处理；不因产品故障关闭或绕过授权。
2. 拍照翻译应能完成拍照/选图、文字识别、方向确认、翻译、原图对照、保存与导出。当前 2908 的图片已进入扫描页，但实机错误为“当前授权服务未开放”；上轮单次测试窗口已关闭且无未过期许可。它解释本次拦截，**不证明 OCR 或翻译在有效许可下已经通过**。
3. 中英自动识别和自动反向已有双识别通路与合成路由测试，但 `automaticLanguageQualified=false`，真实混说、误判、资源、性能和 8 秒队列尚未通过。已有固定中文→英文短句为用户听感反馈，不代替自动模式验收。
4. 当前端侧选择被代码及签名许可共同限制为中英；iOS TTS 当前只按语言自动选系统声音。旧 38 项语言目录和 10 项服务端音色配置尚在源码；它们不代表手机端有对应模型、资源或相同音色，也不代表旧服务当前可用。
5. 3001 仅是已构建、未安装的开发 QA 候选，包含停止回执及续签优化；**不包含本方案的多语言、音色或拍照新功能**。当前服务保持关闭。
6. 3001 App 源码快照 `c46bb642d28435d1fe0a3b360a019c701dbe01e1` 与现役 Cloudflare Worker 的独立源码 `efd87c675516dcdbc16feeabaefb31c3a0035517` 分叉：两者共有祖先为 `c132540a`，后者包含服务端环境隔离和 QA 边缘版本观测。推送 3001 源码不意味着服务端版本相同；后续开发与部署前须分别合并/核对，不能用 App 快照中的旧服务端覆盖现役 Worker。

Apple 说明 `TranslationSession` 的译文处理在设备上，但可能收集不含原文/译文的 API 使用和性能元数据（如 App 标识及语种）；本方案的“纯端侧”指业务内容与推理，不虚称设备或系统永不联网。[Apple TranslationSession](https://developer.apple.com/documentation/translation/translationsession)

## 2. 约束和需明确的产品取舍

- **语言目标**：逐项盘点并尝试恢复原 38 项：中文、英语、法语、葡萄牙语、西班牙语、日语、土耳其语、俄语、阿拉伯语、韩语、泰语、意大利语、德语、越南语、马来语、印尼语、菲律宾语、印地语、繁体中文、波兰语、捷克语、荷兰语、高棉语、缅甸语、波斯语、古吉拉特语、乌尔都语、泰卢固语、马拉地语、希伯来语、孟加拉语、泰米尔语、乌克兰语、藏语、哈萨克语、蒙古语、维吾尔语、粤语。每项分别记录 OCR、语音识别、文字翻译、朗读和允许的语言对，不把一项支持外推为全链支持。
- **不可静默降要求**：设备或系统不支持的项目列明原因、影响和替代；不能仅显示旧名字或改宽许可就宣称 38 种均可用。若用户要求全部为首发硬要求，而系统/设备无法满足，保持阻断并向用户提交补充端侧模型方案或明确降低范围的选择。
- **自动反向的边界**：推荐由用户选择两种对话语言 A/B，再在这两种语言中自动识别并反向；中英为第一个真实验收对。没有预设范围、从全部 38 语言任意自动识别是额外目标，现有两路方案不证明可实现。Apple 文档说明 iOS 同时识别资源存在限制，不能把 38 个识别器同时启动作为默认设计。[SpeechAnalyzer 资源限制](https://developer.apple.com/documentation/speech/speechanalyzer/setmodules%28_%3A%29)
- **音色取舍**：优先开放手机当前可用的 Apple 系统声音，按语言分别选择并在断网验收；旧 10 个声音及其方言基于原服务端预设，不能保证系统声音一一同音色。若首发必须 1:1 复现旧音色，需另行评估可授权、可离线运行的端侧模型、体积和性能，不能暗中调用旧服务。[Apple 声音列表](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice/speechvoices%28%29)
- **干净手机和首装资源**：3001 IPA 仅打包 VAD，不完整包含 Apple 系统语音/翻译资源。推荐首启明确提示、由用户同意从 Apple 下载所需语言资源；资源就绪后断网执行本地业务。如果要求“干净手机安装后完全不下载即可离线使用”，现有系统资源方案尚不能保证，必须先评估可随包分发的端侧资源、授权及包体后再决定；不能把一次联网准备写成开箱全离线。[Apple 已安装语言会话要求](https://developer.apple.com/documentation/translation/translationsession/init%28installedsource%3Atarget%3A%29)
- 保持现有中国大陆首发、Apple 登录、合格用户免费 7 天及其后 ¥10/月规则。设备许可有效期不超过 30 分钟，且不能超过订阅、登录和已批准 QA 窗口截止；云端主动撤销在已签发离线许可内无法保证即时抵达，边缘切换也曾出现短暂滞后，不承诺无网络即时强停。

## 3. 技术方案

### 3.1 拍照翻译

- 复用现有页面、`ScanTranslationController`、图片选择、Vision `OcrBridge`、系统 Translation、位置叠加和本地历史；不引入服务端模型回退。先保留现有“拍照/选图 → 识别文字 → 翻译”操作，不擅自改变交互。
- 整理授权、相机/相册权限、图像读取、OCR、语言资源、翻译和保存六个阶段，明确错误与恢复动作；授权不可用时保留已选图片及已完成结果，不清空或重复购买。许可到期时停止本地处理，拒绝迟到结果；已确认的内容不丢失。
- OCR 可用语种按所用 Vision 请求的真实能力查询，不对不支持的 `recognitionLanguages` 强行塞入全部语言；根据已选语言对/用户选择设置优先级，并验证中文与其他语种混排限制。[Apple Vision 能力查询](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/automaticallydetectslanguage)
- 文本语种判断使用本机候选语言证据与置信度；短数字、混语或不确定时让用户确认方向，避免把日文、拉丁语系等强判成中/英。[Apple 文本语种识别](https://developer.apple.com/documentation/naturallanguage/nllanguagerecognizer)
- 保留 OCR 原文、翻译分块坐标和原图预览；数字、金额、订单号与否定词建立保护和一致性检查，无法可靠恢复时提示复核，不静默改变内容。状态日志只记录阶段、耗时、错误类别，不保存真实照片或原文。

### 3.2 自动识别和反向

- 保留一条麦克风采集、VAD 和音频会话；对用户选定的 A/B 语言对复用现有双路识别和置信度/时间对齐路由，不突破系统资源限制。语言资源未安装、其中一路不可用、证据不足或第三种语言难以确认时明确提示并提供手动选择，不猜测方向、不转云。
- 最终语言为 A 时译成 B，为 B 时译成 A。翻译结果与原会话、轮次、语言对和授权代次绑定，切换、停止、到期后拒绝旧结果；翻译等待和队列规则保持现有 8 秒上限。
- 同句混语和朗读时插话分别纳入验收；若双路识别仅能在完整轮次后判断，须测量由此增加的延迟，不能宣传已提供实时双语临时字幕。若要支持“无预选、全部语言自动识别”，先单列端侧 LID 模型、权限、包体及准确率方案，经用户确认后才引入。

### 3.3 多语言能力目录和许可

- 以旧目录为清单，不覆盖用户原设置；分别查询 `SpeechTranscriber` 支持/安装状态、Translation 语言对状态、Vision OCR 支持和设备实际 TTS 声音。语言/地区/书写系统使用 BCP 47 对照，不能把简体、繁体、粤语和不同地区口音混为同一语种。[SpeechTranscriber 可用范围](https://developer.apple.com/documentation/speech/speechtranscriber) · [Translation 语言对状态](https://developer.apple.com/documentation/translation/languageavailability/status)
- UI 按功能展示“可用、需准备、此设备不支持、尚未验收”，只有真实能力与原质量门禁都通过才作为可用选项；OCR、文字翻译、ASR、TTS 各自显示能力，不能因为某项缺失伪称整条链路支持。
- 现有 1.0 签名许可、原生守卫和服务端 profile 目前仅允许 `zh/en`。扩展语言须协同定义能力版本、许可 claims、原生匹配规则和服务端签发，覆盖旧许可与新 App 的兼容；不能只放开客户端列表，也不能放宽身份、签名、30 分钟及到期校验。真实迁移、服务部署与启用另行批准。
- 不覆盖旧设置文件或旧语言/音色选择；新增独立版本化偏好并保留迁移前快照。对当前版本不支持的旧选择展示原因，由用户选择替代，不把不可用旧值静默写成默认值。

### 3.4 端侧音色选择

- 扩展已有系统声音目录/原生桥接，按当前目标语言展示系统可用声音的名称、语言/地区和质量；显式选择后保存设备内的声音标识，播放时必须使用该标识并校验语言、授权和资源。
- 首次启动沿用系统默认；声音失效/未下载时说明并由用户选择重新准备或同语言默认，不静默换地区、换性别或转云。中文、英文和新增语种各自独立记录偏好。继续遵循现有安全策略，不擅自启用个人/新奇声音或上传声音样本。
- 将旧 10 项分别映射为“可由系统声音近似／尚无可用等价项／需额外端侧模型评估”。近似声音不冒称原音色；没有等价项不能悄悄删除或虚构可用性。

## 5. 测试计划和验收标准

沿用现有 [1.0 端侧后续验收计划](../v10-on-device-p1-p2-20261027/NEXT_PHASE_PLAN.md)：关键否定、数量、编号、金额及日期错误为 0；已准备资源情况下，启动至真正就绪 P95 ≤5 秒、可译文本至完整译文 P95 ≤2 秒、停说至完整译文 P95 ≤3 秒、停说至朗读首音 P95 ≤5 秒。首次下载及冷启动单列，不能把失败剔除后只报均值。达不到则如实阻断，不自动降低标准。

| 测试 | 范围和可验收结果 |
| --- | --- |
| 本地逻辑与隐私 | 使用合成内容测试扫描错误、语言表、设置迁移、音色失效、授权到期、旧代回调、并发与重入；缺资源/断网/拒绝权限均不向模型服务上传内容。源码/包/部署/设备证据分别标注。 |
| 拍照 | 优先复用原固定 40 张 OCR 验收集；先确认素材仍存在及使用许可，缺失时另列替代集，不伪称同集。包含可读证件式布局但不使用真实个人资料、旋转/小字/多栏/模糊及中英混排。40 张逐条记录可读区域、方向、数字/否定/实体、译文、坐标和导出；可读关键字段无错误，失败可恢复且原文保留。 |
| 中英自动反向 | 提议固定 120 个清晰真人语句（中英各 60，至少 30 次语言转换，含至少 40 个数字/否定/编号难例）及 20 个纯数字、混语、噪声或证据不足难例，标注说话人、输入、输出和耗时。清晰语句错误方向 0、正确且完成 ≥95%，不确定不超过 5%；关键语义错误 0。不确定样本不允许猜测输出。上述样本数与 95% 为本方案待用户确认的新增验收指标。 |
| 新增语言 | 先产出 38 项真实设备能力矩阵。每个声称可用的新增语言对，至少按两个方向各 20 段真实语音及对应文本/照片做定向筛查，记录错误、拒绝率、延迟和资源；这只是筛查，不能自动替代完整发布质量验收。未满足原质量标准或无真人样本的语言不得标通过。 |
| 音色与队列 | 各首发语言至少两种设备实际可用的不同系统声音（若设备不足则如实阻断相应要求）；逐一验证选择、重启保持、缺资源、断网可用、听感及语言匹配。中英文原有插话、旧句停止、新句完整朗读、8 秒排队暂停与字幕保留均重测。 |
| 授权和离线 | 测有效、到期、注销/退款、切账号、改钟、重启、回包迟到、无网络和恢复；保留真实旧数据和签名回执，不能人工造权益或强制结算。另经批准领取足够长的单次许可，飞行模式下连续运行 30 分钟并验证截止后无新 OCR/译文/声音，联网后核对唯一回执。当前 10 分钟 QA 窗口不能代替 30 分钟验收。 |
| 稳定性与容量 | iPhone 14 Pro 连续 30 分钟以上，记录峰值内存、热状态、电量变化、前后台/来电恢复；10 个账号控制面模拟与一台手机的结果分开。十台真实设备并行尚无条件时，标未验证，不把模拟当十人实测。 |
| 数据与安装 | 用获批的隔离或新设备验证干净首次安装/资源准备；现有设备仅经批准的保数据覆盖，安装前两份稳定备份、安装后逐文件核对，保留原 Keychain、历史和已下载资源。 |

测试素材应使用用户授权的人声及无真实个人/金融信息的图片；不保存原始音频、照片或识别内容到公开日志。测试期间不充值、不新购订阅或调用付费模型；既有 Sandbox 订阅可加速续期但不是真实扣费。模型 API 调用预算为 ¥0，Apple 语言资源下载产生的数据流量及现有控制服务费用不在此假设为零。单机中文基线、40 张图片和 30 分钟长测通常需数小时；新增语言约按每对至少 40 段真人样本与听审线性增加，全部 38 项不能保证一次窗口完成。

## 6. 审批与交付

本方案及测试范围先经用户确认。用户确认前不开发产品代码；之后本地实现和模拟可继续，但精确云端迁移/部署、设备安装、真实语音/照片实验、增加语言资源、购买/充值及 App Store 送审或发布仍按当时具体范围另行确认。出现需更换模型、无法达到 38 项／旧音色／质量或首次无下载要求时，列出差距让用户决定，不擅自降级。

本轮另行清点 Git 推送范围和可重建过程缓存；GitHub 公共分支推送不等于 App Store 发布。已批准的历史回执、数据备份、源码快照及可回退候选不得当作可清理临时文件。
