## 仍未完成/未证明

1. **自动语种仍有实现缺口。** 当前复用Apple ASR只接固定中文/英文，`auto`明确拒用，原入口未静默删除。不得据此宣布自动识别或自动双向已完成；首发保留则需继续实现与实测，延期须明确确认。
2. 本轮没有运行语言模型。真实中英质量、关键否定/数字、朗读时识别、插话完整续读、实际8秒行为、延迟/内存/耗电/发热、30分钟与十台实机均未验证。合成链路不等于真实听感通过。
3. 系统模型由iOS管理，不能声称全部在IPA；只复用5个既有VAD资源。干净手机的资源准备/离线使用仍需实机证据。
4. 实际月SKU、CNY价格点、优惠/订阅组资格、IAP凭据、Apple根、三种独立Key、App Attest与App许可公钥未做真实配置核对或绑定；没有真实试用/购买/扣费。若有旧合法付费权益，兼容情况另核，不把旧测试额度恢复为权益。
5. 没有新签名包、线上资源、迁移、部署、安装或发布。新CF数据备份、告警/恢复、真实Apple通知与故障恢复仍待后续阶段；旧服务、旧账与历史队列未恢复。

因此，本轮交付是可审阅的本地源和模拟证据。P3及之后按[下一步方案](NEXT_PHASE_PLAN.md)推进，正式发布资格仍未取得。
