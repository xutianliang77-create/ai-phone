# 国内版账号与首启合规设计

版本：v1.0  
日期：2026-07-06  
关联：`docs/domestic-design-review-action-plan.md`、`docs/domestic-app-detailed-functional-design.md`

## 1. 目标

补齐国内版发布阻断项中的账号身份和首启合规能力，让同传、Call Link、支付、PSTN、AI Agent、历史和删除权都有明确归属。

本设计解决：

- 用户是谁。
- 哪些能力可以游客试用。
- 什么时候必须登录或实名。
- 首启如何取得用户协议和隐私政策同意。
- 云端语音处理如何取得敏感个人信息单独同意。
- 用户如何撤回同意、删除记录、注销账号。
- 非必要 SDK 何时允许初始化。

## 2. 账号状态

| 状态 | 说明 | 可用能力 |
| --- | --- | --- |
| 未同意 | 首次打开 App，未接受用户协议和隐私政策 | 只能查看首启合规页 |
| 游客 | 已接受协议，但未登录 | 端侧同传、本地历史、端侧诊断 |
| 已登录 | 手机号验证码登录成功 | 在线同传、Call Link、云历史、支付、术语库 |
| 已实名 | 完成实名或服务商要求的身份校验 | PSTN、AI Agent、可能涉及通信服务的灰度能力 |
| 已注销 | 用户发起注销并完成处理 | 不可登录旧账号；按保留要求删除或匿名化数据 |

## 3. 游客边界

游客允许：

- 使用端侧同传。
- 使用本地 OCR。
- 保存本地历史。
- 查看隐私与合规文档。
- 查看模型链路诊断的本机部分。

游客不允许：

- 在线同传。
- Call Link 创建或加入 App 端房间。
- PSTN 拨号。
- AI Calling Agent。
- 支付和购买。
- 云端历史同步。
- 跨设备术语库。

触发受限功能时：

1. 显示登录页。
2. 说明该功能需要账号归属和云端处理。
3. 登录成功后回到原操作。
4. 如果功能涉及语音上云，继续检查单独同意。

## 4. 登录方式

首发国内版：

- 手机号 + 短信验证码。
- 支持 Apple 登录作为 iOS 辅助方式，但手机号仍作为国内通信和支付归属主标识。
- 开发阶段可保留 `guest-user` 测试兜底，但发布门禁必须确认测试自动账号关闭，且不能作为云端主用户。

登录安全：

- 短信验证码 60 秒重发。
- 单手机号每日验证码次数限制。
- 同设备失败次数限制。
- 登录 token 支持刷新和撤销。
- 退出登录不删除本地历史，但云端能力停用。

当前服务端状态：

- `services/api-server/src/modules/account/sms-provider.ts` 已提供 `debug` 和 `http` 两类 SMS Provider。
- 本地开发默认使用 `debug` Provider；生产发布门禁要求 `SMS_PROVIDER=http`，并校验 HTTPS 短信网关、API Key、模板 ID、签名和超时配置。
- `services/api-server/src/modules/account/account-readiness.ts` 已接入 `/health` 和 `/health/release-ready`，发布前要求 `NODE_ENV=production`、强 `AUTH_OTP_SECRET`、关闭 `AUTH_DEBUG_OTP` 和关闭测试自动账号。
- 验证码发送失败时不落库 OTP challenge，避免用户收到失败但服务端已生成可登录验证码。
- `services/api-server/src/modules/account/sms-otp-limits.ts` 已接入 60 秒重发冷却、单手机号 24 小时 10 次发送上限、同设备验证码失败 5 次锁定。
- 真实短信商户、模板内容、发送回执、策略阈值运营配置和真机收码体验仍为发布前验收项。

## 5. 实名边界

P0/P1 不强制所有用户实名。

必须实名或完成服务商要求身份校验的能力：

- 拨打手机号翻译电话。
- AI Calling Agent 外呼。
- 可能被监管认定为通信服务或批量外呼的能力。

实名材料不由 App 自行扩大采集。优先采用：

- 持牌 PSTN/VoIP 服务商的实名或企业资质流程。
- 企业版对公认证。
- 必要时调用合规第三方实名服务。

## 6. 首启同意

首次启动必须显示：

- 用户协议。
- 隐私政策。
- 语音、字幕、译文、历史、支付和日志的处理摘要。
- “同意并继续”按钮。

首启同意规则：

- 用户未勾选前按钮不可用。
- 不同意时不能进入 App 主功能。
- 同意记录保存版本号和时间。
- 协议版本升级且涉及重大变更时，重新弹出同意页。
- 同意前不初始化非必要 SDK。

当前实现：

- App 已接入首启同意门。
- 同意版本：`domestic-initial-consent-v1`。
- 本地记录：`compliance_consent.json`。

## 7. 敏感个人信息单独同意

语音属于敏感个人信息。以下能力首次使用前必须单独确认：

- 在线同传。
- Call Link。
- PSTN 电话翻译。
- AI Calling Agent。
- 云端 TTS 或云端摘要。

单独同意弹窗必须说明：

- 会处理麦克风音频、字幕和译文。
- 是否保存原始音频。默认不保存。
- 会调用哪些模型或服务商。
- 数据用途：实时翻译、字幕、TTS、历史、用量、故障排查。
- 用户可以撤回同意，撤回后云端能力不可继续使用。

单独同意记录字段：

- `userId`
- `consentType`
- `version`
- `acceptedAt`
- `regionEdition`
- `feature`
- `deviceId`

## 8. SDK 延迟初始化

同意前允许初始化：

- Flutter 基础框架。
- 本地主题、语言、首启页面。
- 必要的崩溃保护本地捕获。

同意前不允许初始化：

- 支付 SDK。
- 推送 SDK。
- 第三方统计 SDK。
- 远程崩溃上报 SDK。
- 非必要广告、增长或归因 SDK。

首发如果没有接统计和推送，也必须在设计中保留延迟初始化约束。

## 9. 注销和删除

用户可执行：

- 删除单条本地历史。
- 删除云端会话。
- 导出个人信息副本。
- 撤回云端语音处理同意。
- 注销账号。

注销处理：

1. 用户在“我的 - 隐私与合规 - 客服与账户”进入注销入口。
2. 服务端校验登录态和风险。
3. 展示注销影响：余额、订阅、历史、术语库、Agent 任务。
4. 用户二次确认。
5. 服务端进入注销处理期。
6. 按法定保留要求删除或匿名化个人信息。
7. 保留必要账务、风控和合规日志。

## 10. 数据归属

| 数据 | 游客 | 已登录 |
| --- | --- | --- |
| 本地历史 | 设备本地 | 设备本地，可选同步 |
| 在线会话 | 不允许 | 归属 userId |
| Call Link | 不允许创建 | 归属 host userId |
| Guest Web | 免安装加入，但必须单次告知同意 | 可绑定注册转化 |
| 术语库 | 本地临时 | 云端 userId |
| 支付权益 | 不允许 | 归属 userId 和订单 |
| Agent 任务 | 不允许 | 归属 userId，外呼前需授权 |

## 11. API 需求

已接入：

- `POST /auth/phone/request-code`
- `POST /auth/phone/login`
- `POST /auth/logout`
- `GET /account/me`
- `POST /account/delete`
- `GET /account/export`
- `POST /account/consents`
- `GET /account/consents`

待补：

- `DELETE /account/consents/:type`

发布前门禁：

- 未登录不能创建在线会话。
- 未登录不能创建 Call Link。
- 未登录不能下单。
- 未单独同意不能开始云端语音处理。
- 注销入口和客服入口可访问。

## 12. App 页面需求

新增或调整：

- 首启同意页：已实现第一版。
- 登录页：手机号 + 验证码。
- 单独同意弹窗：在线同传、Call Link、PSTN、Agent 首次使用时弹。
- 账号页：手机号、登录状态、退出登录、注销账号。
- 隐私与合规页：增加同意记录、撤回同意、个人信息导出。
- 支付页：未登录时先登录。

## 13. 验收标准

P0：

- 首次启动显示协议和隐私政策确认。
- 未同意不能进入 App 主功能。
- 同意后进入同传页。
- 重启后不重复弹出，除非版本升级。
- 同意前不初始化非必要 SDK。

P1：

- 在线同传首次使用弹出语音敏感信息单独同意。
- 未登录不能使用在线同传、Call Link 和支付。
- 登录后权益和历史归属 userId。
- 注销入口可访问。

P2：

- PSTN/AI Agent 外呼前完成实名或服务商准入。
- 被叫方告知和同意状态留痕。
- 用户撤回同意后云端语音能力被禁用。

## 14. 待确认

- 正式短信服务商账号、模板、签名和回执联调。
- 验证码频控阈值是否需要按渠道审核或运营风控调整。
- 是否在 P1 启用 Apple 登录。
- 实名能力由 PSTN 服务商承接还是自建第三方实名。
- 注销处理期和账务保留周期。
- 企业版对公认证和发票主体。
