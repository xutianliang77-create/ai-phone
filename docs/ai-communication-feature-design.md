# AI 通讯翻译功能设计文档

版本：v0.1  
日期：2026-07-02  
范围：AI Calling Agent、电话实时翻译、视频/社交 App 通话翻译、面对面同传、Listening Mode、Type-to-Speak、通话字幕、重点高亮、AI 摘要、转写记录、自定义语音、图片/相机/屏幕翻译。  
定位：从“翻译 App”升级为“中英优先的 AI 实时通讯翻译平台”。

## 1. 产品定位

一句话定位：面向跨语言电话、视频会议、面对面沟通和课堂会议的 AI 实时翻译助手。

核心承诺：

- 说中文自动翻英文，说英文自动翻中文。
- 电话、会议、面对面、听讲都能实时字幕。
- 通话结束后自动保存转写、重点和摘要。
- 可输入姓名、地址、数字等敏感信息，让系统翻译并读出。
- 中英优先做深，逐步扩展多语言。

## 2. 关键边界

- 普通 iOS/Android App 不能稳定直接拦截系统电话、微信、WhatsApp、Telegram 的原始音频。
- 电话/社交通话翻译采用自有通话链路、Call Link、VoIP、网页房间或号码中转实现。
- 不宣传“直接监听微信通话”，宣传“发送翻译通话链接，对方点击加入”。
- 自定义语音只做用户授权的个人声音或系统自然声音，不做冒充他人的声音。
- AI Calling Agent 涉及付款、合同、医疗、法律、身份验证时必须请求用户接管。

## 3. 产品结构

底部主导航建议 5 个入口：

| 入口 | 中文名 | 核心任务 |
| --- | --- | --- |
| Live | 同传 | 面对面 Talk Mode、Listening Mode、普通实时同传 |
| Call | 通话 | AI Calling Agent、电话实时翻译、Call Link |
| Lens | 扫描 | 相机、图片、屏幕截图翻译 |
| Records | 记录 | 通话/同传/图片历史、转写、摘要、导出 |
| Me | 我的 | 语言、语音、订阅、隐私、术语库、用量 |

## 4. 功能优先级

| 阶段 | 功能 |
| --- | --- |
| MVP | 面对面同传、Listening Mode、双语字幕、转写记录、历史详情、导出、Type-to-Speak、基础 AI 摘要 |
| P1 | 通话房间/Call Link、通话双语字幕、重点高亮、术语库纠错、图片/相机 OCR、自然 TTS |
| P2 | 拨打手机号翻译电话、PSTN 服务商桥接、AI Calling Agent、App 内 VoIP 电话、视频/社交 App 链接通话翻译、团队词表 |
| P3 | 自定义语音、授权语音克隆、屏幕实时翻译、企业控制台、多语言扩展 |

## 5. 面对面 Talk Mode

用户目标：两个人面对面，各说各的语言，App 自动识别并翻译。

入口：底部“同传” > “面对面”。

主流程：

1. 用户点击“开始”。
2. App 请求麦克风权限，启动 ASR。
3. 识别中文时自动输出英文，识别英文时自动输出中文。
4. 每条消息显示原文、译文、语言标识、时间。
5. 点击“结束”后保存会话。

关键规则：

- 默认自动识别语言。
- 支持关闭朗读，只显示字幕。
- 支持手动切换源语言/目标语言作为兜底。
- 支持术语库纠错。
- 字幕超过一屏自动滚动到最新。

验收标准：

- 3 秒内出现识别反馈。
- 中文和英文快速切换时不需要手动切方向。
- 结束后历史详情可打开，原文和译文都完整保存。

## 6. Listening Mode

用户目标：听课、演讲、会议时只听不打扰，不播放译文语音。

入口：底部“同传” > “听讲”。

差异规则：

- 默认关闭 TTS 播放。
- 字幕字体更大，适合远距离观看。
- 支持“重点标记”按钮。
- 会后默认生成摘要。
- 支持课堂、会议、讲座、客服、医疗等场景标签。

输出内容：

- 实时双语字幕。
- 逐句转写。
- 用户手动标记重点。
- AI 自动重点。
- 会后摘要和待办。

## 7. 电话实时翻译

用户目标：与对方通话时，双方各说各的语言，对方听到翻译后的语音，同时看到字幕。

实现路线：

- MVP 不做系统电话拦截。
- P1 做 Call Link：双方进入同一个网页或 App 通话房间。
- P2 必做拨打手机号翻译电话：用户输入手机号，后端通过 Twilio、Telnyx 或同类 PSTN 服务商拨号，用户在 App 内 VoIP 接入。
- P3 评估 CallKit、运营商能力和地区合规。

主流程：

1. 用户进入“通话”。
2. 选择“发起翻译通话”。
3. 选择双方语言。
4. 生成 Call Link，分享给对方。
5. 双方进入房间后开始通话。
6. 系统实时转写、翻译、播放 TTS。
7. 通话结束后保存转写、重点、摘要。

关键状态：

- 等待对方加入。
- 正在拨号。
- 对方未接听。
- 对方忙线。
- 对方网络不稳定。
- 翻译延迟过高。
- TTS 播放失败。
- 余额/分钟不足。
- 对方拒绝麦克风权限。

### 7.1 拨打手机号翻译电话

用户目标：输入对方手机号，对方接到普通电话，接通后双方开始翻译通话。

技术路径：

- 用户侧：App 内 VoIP/WebRTC 通话，不切到系统 Phone App。
- 对方侧：接听普通 PSTN 电话。
- 服务端：通过 PSTN 服务商发起电话，并桥接双方音频。
- AI 链路：ASR -> 翻译 -> TTS -> 双向播放。
- 记录链路：实时字幕、转写、重点、摘要、用量扣费。

主流程：

1. 用户点击“拨打手机号”。
2. 输入对方手机号，选择对方语言。
3. App 展示费用预估和录音/AI 翻译提示。
4. 用户确认拨打。
5. 后端通过 PSTN 服务商呼叫对方。
6. 对方接听后，App 自动进入通话中页面。
7. 通话结束后生成双语记录、重点和摘要。

验收标准：

- 用户不需要离开 App。
- 对方不需要安装 App。
- 接通后 3 秒内显示第一条识别反馈。
- 通话记录必须包含电话状态、消耗分钟和服务商 call id。
- 余额不足时禁止发起拨号。

## 8. 视频/社交 App 通话翻译

用户目标：通过链接让对方加入翻译房间，覆盖 WhatsApp、WeChat、Telegram、LINE 等社交通讯场景。

流程：

1. 用户创建翻译房间。
2. 选择分享渠道：短信、微信、WhatsApp、Telegram、LINE、邮件。
3. 对方点击链接进入网页。
4. 双方在翻译房间完成语音/视频通话。

阶段：

- P1：只做语音房间。
- P2：做视频房间。
- P3：做会议平台插件或桌面助手。

## 9. AI Calling Agent

用户目标：让 AI 帮用户打电话，完成预约、询问、客服沟通。

适合场景：

- 预约餐厅、医生、修车、理发。
- 查询营业时间、价格、库存。
- 联系客服修改订单。
- 英语不熟时由 AI 代为表达。

Agent 流程：

1. 用户选择任务类型。
2. 用户填写对方号码、目标、时间偏好和个人信息。
3. AI 生成通话计划和话术。
4. 用户确认后 AI 发起通话。
5. 通话中用户可实时查看转写并接管。
6. 结束后生成结果：成功、失败、待人工处理。

安全限制：

- 拨打前必须用户确认。
- 不能冒充政府、银行、医院工作人员。
- 不能处理高风险金融、法律、医疗决策。
- 涉及付款、合同、身份验证时必须请求用户接管。
- 必须保存通话意图、用户授权和接管记录。

## 10. Type-to-Speak

用户目标：把姓名、地址、号码、药名、产品型号等难识别内容输入，让系统翻译并朗读。

入口：

- 同传页底部“键入朗读”。
- 通话中按钮“输入并朗读”。

规则：

- 数字、地址、姓名默认逐字/逐段清晰朗读。
- 支持收藏常用短语。
- 通话中朗读时暂停麦克风回声识别。
- Type-to-Speak 内容也进入历史记录，并标记来源。

## 11. 字幕、重点、摘要和转写

每条字幕包含：

- 说话方：我、对方、说话人 1。
- 原文。
- 译文。
- 时间戳。
- 是否重点。
- 是否由 Type-to-Speak 发出。

字幕操作：

- 复制。
- 重新翻译。
- 标记重点。
- 纠正术语。
- 播放译文。

自动重点类型：

- 时间、地点、金额。
- 人名、电话、订单号。
- 承诺事项。
- 待办事项。
- 风险或不确定内容。

AI 摘要内容：

- 一句话结论。
- 关键事项。
- 待办列表。
- 重要时间/地点/金额。
- 双语摘要。
- 识别不确定提示。

## 12. 自定义语音输出

阶段设计：

- MVP：系统自然男声/女声。
- P1：语速、音量、音色选择。
- P2：用户录制授权个人声音。
- P3：多设备同步个人语音。

合规：

- 必须录制授权确认。
- 禁止上传他人声音生成克隆。
- 每次使用自定义声音可显示“使用我的授权语音”。

## 13. 图片、相机、屏幕翻译

用户目标：翻译菜单、合同、表格、网页截图、聊天截图。

入口：底部“扫描”。

功能：

- 拍照翻译。
- 相册导入。
- 屏幕截图导入。
- 区域选择。
- 保留原排版译文覆盖。
- OCR 文本复制。
- 保存到记录。

P1 验收：

- 菜单、路牌、表格能识别。
- 支持中英双向。
- 支持复制和分享。

## 14. 订阅与用量

| 版本 | 权益 |
| --- | --- |
| Free | 每月 30 分钟同传、3 条历史、基础扫描、无 AI Agent |
| Pro | 600-1000 分钟同传、历史不限、导出、AI 摘要、基础术语库 |
| Plus | 更高分钟数、通话房间、AI Agent、领域纠错、高质量云模型 |
| Credits | 电话、视频、AI Agent、云端高质量语音按量扣费 |

付费墙触发：

- 免费分钟用完。
- 导出 PDF。
- 生成 AI 摘要超过免费次数。
- 创建通话链接。
- 使用 AI Agent。

## 15. 核心验收指标

| 指标 | 目标 |
| --- | --- |
| 同传启动 | 3 秒内可见识别反馈 |
| 普通字幕延迟 | 1-3 秒出现译文 |
| 通话翻译延迟 | P1 目标 2-5 秒内可接受 |
| 长会话 | 至少 30 分钟稳定记录 |
| 历史保存 | 结束后 100% 可打开详情 |
| 摘要生成 | 30 秒内生成基础摘要 |
| Type-to-Speak | 通话中可插入播放，不破坏当前转写 |
